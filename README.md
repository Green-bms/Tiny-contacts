# Tiny-contacts



📌 Overview <br>
Tiny contacts is an open-source hardware project designed to display personal contact information, social links, or digital business cards in a portable, battery-efficient form factor. Built with a focus on low power consumption and compact PCB design, it is ideal for makers, networking events, or wearable electronics projects.

✨ Features <br>
Compact Form Factor: Designed for portability and wearable integration.

Low Power Consumption: Optimized power management for long battery life.

Custom PCB Design: Clean layout tailored for hand-soldering or SMD assembly.

Open Source: Fully customizable hardware and firmware.
