# Tiny Contacts 🔌

![Status](https://img.shields.io/badge/hardware-v1.0-blue.svg)
![Size](https://img.shields.io/badge/dimensions-42x38%20mm-brightgreen.svg)

An ultra-compact 4-channel SMD relay board engineered for space-constrained IoT and home automation setups. Designed to interface low-power microcontrollers (3.3V/5V) with medium loads seamlessly.

![alt-text](https://github.com/Green-bms/Tiny-contacts/blob/master/Pictures/Tiny%20contacts%20Github.png)

---

## 🛠️ Key Features

* **Ultra-Compact Footprint:** Only **42 mm x 38 mm**, perfect for custom enclosures and tight spaces.
* **4-Channel Relay Control:** Built with **Omron G6K-2F-Y** low-signal SMD relays for fast, reliable switching.
* **Integrated Driver IC:** Powered by the **ULN2003A** Darlington transistor array, protecting MCU GPIO pins from inductive kickback.
* **Universal MCU Compatibility:** Fully compatible with ESP32, ESP8266, Arduino, ATtiny, and STM32.
* **Status LEDs:** Onboard indicators for power state and channel activity monitoring.

---

## 📊 Technical Specifications

| Parameter | Specification |
| :--- | :--- |
| **Board Dimensions** | 42 mm x 38 mm |
| **Operating Voltage (VCC)** | 5V DC |
| **Logic Input Level** | 3.3V – 5V TTL |
| **Relay Type** | Omron G6K-2F-Y (SMD, Low-Signal) |
| **Driver IC** | ULN2003A |
| **Channels** | 4 Independent Relays |
